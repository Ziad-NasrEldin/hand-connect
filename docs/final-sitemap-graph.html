Role Flows

Journey Boards

Each board shows the intended path through the product without mixing it into the route matrix.

Customer

  • Discover: / -> /search -> /providers/:id
  • Authenticate: /login or /register
  • Contact: reveal WhatsApp or start message
  • Message: /messages -> /messages/:id
  • Review: /reviews/new/:providerId after contact
  • Safety: report provider, review, or message

Provider

  • Apply: /join-provider with identity upload
  • Wait: /pending until admin approval
  • Measure: /dashboard metrics and reviews
  • Edit: /profile/edit settings
  • Promote: /visibility boosts and area expansion
  • Respond: shared /messages routes

Admin

  • Overview: /admin stats
  • Applications: approve/reject providers
  • Providers: suspend, ban, unban
  • Professions: create/toggle categories
  • Visibility: confirm/reject manual payment
  • Moderate: reports and audit log

Firebase And Demo DB

Data Model

Domain entities mirrored by TypeScript types, demo localStorage data, Firebase collections, rules, indexes, and storage paths.

Core Collections

  • users: role, status, profile, phone, language
  • providers: status, profession, areas, coverage, WhatsApp, paid visibility, metrics
  • providerIdentityDocuments: private provider/admin identity review
  • professions: Arabic/English category metadata
  • contacts: WhatsApp reveal or platform message contact events
  • conversations/messages: participants, unread counts, message records
  • reviews: contact-gated rating and comment records

Operations Collections

  • visibilityRequests: boost or area expansion, payment status, product snapshot
  • analyticsEvents: server-owned event records, admin-readable
  • adminActions: audit entries for admin decisions
  • reports: provider, review, or message abuse reports

Storage Paths

  • providerPhotos/{providerId}/{fileName}: public read, owner write
  • identityDocuments/{providerId}/{fileName}: admin or owner read, owner write
  • all other paths: denied

Server Surface

Backend

Firebase callable/business exports plus Vercel utility endpoints.

Firebase Functions

  • providers: approveProvider, rejectProvider, suspendProvider
  • reviews: createReview, hideReview, recalculateRating
  • analytics: trackProfileView, writeAnalyticsEvent
  • visibility: approveVisibility, approveVisibilityRequest, rejectVisibilityRequest, expiredVisibilityPatch
  • engagement: revealWhatsApp, startConversation, reportProvider, reportReview, reportMessage
  • abuse/audit: isPotentialLeadSpam, writeAudit

Vercel API

  • GET /api/health: ok, service, provider, environment, region, timestamp
  • POST /api/abuse/check: lead-spam helper
  • POST /api/admin/assert-reason: validates admin reason
  • POST /api/reviews/recalculate: rating aggregate helper
  • POST /api/visibility/approve: paid-until calculation helper
