## Description
Herafy is a Cairo-focused directory for finding home-service professionals.

Use Herafy to:

- Search by profession and service area.
- View verified provider profiles, ratings, and service details.
- Contact providers directly through messaging or WhatsApp reveal.
- Review providers after a real contact.
- Report unsafe or abusive content for admin moderation.

Herafy is a connection layer. It does not employ providers, assign jobs, process payments, set prices, or guarantee service outcomes.
